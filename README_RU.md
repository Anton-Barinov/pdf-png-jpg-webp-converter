## ⚡ О проекте

**Universal Converter** — это быстрый, автономный веб-сервис для конвертации и сжатия изображений и PDF-документов, работающий полностью локально на вашем оборудовании.

В отличие от коммерческих облачных сервисов (таких как CloudConvert, iLovePDF или TinyPNG), ваши документы **никогда не покидают пределы вашего сервера**, не передаются в чужие облака и **безвозвратно стираются через 5 минут**.

---

## 🚀 Основные возможности

### 🖼️ Конвертация и оптимизация изображений
- **PNG $\leftrightarrow$ JPG / JPEG $\leftrightarrow$ WebP:** Мгновенная взаимная смена форматов с настройкой качества сжатия.
- **Lossless сжатие:** Уменьшение объёма фото без потери качества (`optipng`, `jpegoptim`, `cwebp -lossless`) с автоматическим удалением конфиденциальных метаданных (EXIF, геометки GPS).
- **Фото в PDF:** Сборка пачки картинок в единый многостраничный PDF-документ за один клик.

### 📄 Работа с PDF-документами
- **Сжатие и оптимизация PDF:** Эффективное уменьшение объёма «тяжёлых» сканов и документов через Ghostscript с пресетами `eBook` (150 DPI) и `Screen` (72 DPI), а также линеаризацией через QPDF.
- **Склейка PDF (Merge):** Объединение нескольких PDF в один файл с возможностью менять порядок страниц кнопками ↑ / ↓.
- **Разделение PDF (Split):** Постраничная нарезка документа на отдельные файлы в одном ZIP-архиве.
- **Экспорт PDF в картинки:** Преобразование страниц документа в чёткие изображения PNG или JPG.

### 🛡️ Безопасность и конфиденциальность
- **Zero Retention (Строгий TTL 5 минут):** Все исходные файлы и результаты конвертации безвозвратно удаляются через 5 минут четырёхуровневой системой очистки (системный Cron + встроенный GC + моментальная кнопка «Очистить»).
- **Изолированное хранилище:** Временные сессии сохраняются вне корня веб-сервера (`private/`) и недоступны по прямой ссылке из браузера.
- **Проверка Magic Bytes:** Каждый файл проверяется по бинарной сигнатуре содержимого (`finfo`). Скрипты (`.php`, `.sh`, `.exe`) и поддельные файлы немедленно стираются с диска.
- **Защита процессов:** Ghostscript заблокирован параметром `-dSAFER`. В ImageMagick отключены опасные векторные кодеры (`MVG`, `MSL`) и сетевые протоколы. Все вызовы ограничены сторожевым таймером `/usr/bin/timeout 60s`.

### 📱 Удобный и адаптивный интерфейс
- Чистый, спокойный светлый дизайн без визуального шума и тяжелых библиотек (чистый vanilla JS/CSS).
- Удобная мультифайловая загрузка через Drag & Drop.
- Вкладки-фильтры (`Все файлы`, `Картинки`, `PDF`, `Сжатие`).
- Синхронное переключение формата как для всей группы файлов, так и по отдельности для каждого файла.

## 🛠️ Быстрый старт

### Способ 1: Docker Compose (Рекомендуемый — запуск за 30 секунд)

Запуск сервиса в изолированном контейнере со всеми предустановленными утилитами конвертации:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Anton-Barinov/pdf-png-jpg-webp-converter.git
cd pdf-png-jpg-webp-converter

# 2. Запустите контейнер
docker compose up -d
```

Откройте в браузере: **`http://localhost:8080`**

Остановить контейнер:
```bash
docker compose down
```

---

### Способ 2: Автоустановка на сервер (Ubuntu / Debian VPS)

Для установки на чистый сервер без Docker:

```bash
git clone https://github.com/Anton-Barinov/pdf-png-jpg-webp-converter.git
cd pdf-png-jpg-webp-converter
sudo bash install.sh
```

Скрипт автоматически:
1. Установит все пакеты (`nginx`, `php-fpm`, `poppler-utils`, `webp`, `optipng`, `jpegoptim`, `qpdf`, `ghostscript`, `imagemagick`).
2. Настроит виртуальный хост Nginx под ваш домен или IP.
3. Выставит безопасные права доступа на приватное хранилище (`750`).
4. Настроит минутный Cron-таймер для очистки файлов старше 5 минут.

---

### Способ 3: Ручная установка

<details>
<summary>Нажмите, чтобы развернуть инструкцию по ручной установке</summary>

1. **Установка системных пакетов:**
   ```bash
   sudo apt-get update
   sudo apt-get install -y nginx php-fpm php-zip php-mbstring \
       poppler-utils webp optipng jpegoptim qpdf ghostscript imagemagick timeout
   ```

2. **Копирование файлов:**
   ```bash
   sudo mkdir -p /var/www/converter/public_html
   sudo mkdir -p /var/www/converter/private/storage/sessions
   sudo cp -r src/index.php src/api.php src/config.php src/assets /var/www/converter/public_html/
   sudo cp -r src/lib /var/www/converter/private/
   sudo chown -R www-data:www-data /var/www/converter
   sudo chmod -R 750 /var/www/converter/private
   ```

3. **Настройка веб-сервера:**
   Укажите `root` виртуального хоста Nginx на `/var/www/converter/public_html` и подключите сокет PHP-FPM.

4. **Настройка автоочистки каждые 5 минут:**
   ```bash
   echo "* * * * * root find /var/www/converter/private/storage/sessions/ -mindepth 1 -maxdepth 1 -mmin +5 -exec rm -rf {} + >/dev/null 2>&1" | sudo tee /etc/cron.d/converter-cleanup
   ```
</details>

## ⚙️ Настройки (.env)

Параметры можно переопределить через переменные окружения или файл `.env`:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `APP_NAME` | `Universal Converter` | Название сервиса в шапке и заголовке страницы |
| `TTL_SECONDS` | `300` | Время хранения файлов в секундах (300с = 5 минут) |
| `MAX_FILE_SIZE_MB` | `100` | Максимальный размер одного файла в МБ |
| `MAX_SESSION_FILES` | `50` | Максимальное количество файлов в одной сессии |
| `DEFAULT_QUALITY` | `90` | Качество сжатия по умолчанию для JPG и WebP (10-100) |

## 🔒 Безопасность

1. **Полная автономность:** Сервис не делает никаких внешних сетевых вызовов, запросов к сторонним API или аналитике.
2. **Аппаратный Air-Gap (Рекомендуется):** На выделенном сервере рекомендуется заблокировать исходящий трафик для пользователя веб-сервера через `iptables`:
   ```bash
   sudo iptables -I OUTPUT 1 -m owner --uid-owner www-data ! -d 127.0.0.1 -j REJECT
   ```
3. **Проверка содержимого:** Загружаемые файлы проверяются по их бинарной структуре, а не по расширению.
4. **Защита от Path Traversal:** Случайный 128-битный UUID сессии и проверка канонического пути через `realpath()`.
5. **Таймаут выполнения:** Все CLI-процессы вызываются с таймаутом 60 секунд для защиты от зависания и DoS-атак.
